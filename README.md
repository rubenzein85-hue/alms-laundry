# alms-laundry
Aplikasi Laundry merupakan project sistem informasi yang dirancang untuk membantu pengelolaan layanan laundry, mulai dari manajemen pelanggan, transaksi, pemesanan, hingga pemantauan status laundry. Dibangun untuk meningkatkan efisiensi operasional dan mempermudah proses pengelolaan bisnis laundry.
